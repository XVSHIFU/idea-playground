这段代码为什么这样写？

① row0 和 col0 到底保存什么？它们不是“第 0 行/列的值”，而是布尔变量：最初的第一行或第一列是否出现过 0。必须先保存，否则后面借用首行首列做标记时，会丢失原来的信息。
② 为什么两个嵌套循环从 1 开始？第 0 行和第 0 列被当作“标记区”，所以只扫描和更新内部区域。matrix[i][0] == 0 表示第 i 行应清零；matrix[0][j] == 0 表示第 j 列应清零。
③ 为什么先打标记、再清零？如果看到 0 就立刻把整行整列都改成 0，新增的 0 会触发更多错误的清零。先记录哪些行列需要清零，再统一更新，就不会发生连锁误判。
④ 为什么首行和首列最后才清零？因为它们还保存着其他行、列的标记。过早清掉会让所有内部单元格都误以为自己要变成 0。
⑤ 复杂度是什么？扫描矩阵与更新矩阵各最多 O(mn)，时间复杂度 O(mn)；只使用 row0、col0 和循环变量，额外空间复杂度 O(1)。
