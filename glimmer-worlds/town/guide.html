观察手记

城镇有自己的节奏。太阳升起，居民出门；有人去田间，有人走向工坊。一天里的许多小事，慢慢决定了一座城的样子。

栖川中的人物、地名、资源与事件都是虚构的。它是一件可以观察和干预的规则模拟作品，记录的是这个小世界里的因果。

从一个居民开始

点开地图上的一个人，跟着他走一会儿。

居民有住处、工作、积蓄和不同的性格，也会饥饿、疲惫、需要陪伴。他们根据时间与当前需求选择去处。到达工作地点后才会生产，休息需要时间，吃饭需要食物和支付能力。

观察面板中的行动告诉你他正在做什么，状态说明他为什么需要这么做。近期记忆会留下生活里的一些变化；朋友关系则让某个居民与小城中的其他人联系起来。

不急着把数字调高。先看看：一个刚领到工资的人去了哪里？一位疲惫的居民什么时候回家？一天结束后，哪些需求还没有被满足？

生活如何循环

栖川采用合作社式的共享仓储经济。农田提供食物，林场提供木材，工坊加工商品。居民到岗劳动产生资源，公共金库支付工资，居民购买食物和商品时，钱再回到金库。工资支付时会扣除设定的税额。

影响人口

小城会出售多余的资源，获得外部收入。仓库紧张时，价格和居民负担会跟着变化；金库紧张时，工资与公共支出也会受限。因此，食物、工作、住房与公共预算需要一起看。

季节与天气会改变生产条件。这里每个季节持续三十个城镇日，天气逐日变化。扩建带来新的容量与岗位，也会消耗现有木材和资金；施工中的建筑需要等到完成，才会发挥作用。

留下来的理由

当居民靠近、交往，关系会逐渐积累。社交状态、朋友、健康、休息和经济处境共同影响生活感受。地图上的一个小点，因此不只是人口统计中的一个单位。

持续不满或生活拮据的人可能离开；当城里有空余住房、生活状况合适时，也可能迎来新居民。开放度影响迁入的机会，住房决定小城能否接纳他们。

日常事件会记录发生了什么。遇到人口变化，不妨回看最近几天：食物是否变得昂贵？工作和住房是否足够？金库是否在持续缩水？这些信息往往比单看一个人口数字更有意思。

关系和生活都有时间尺度

一次补给可以缓解眼前的短缺；一座新农田需要施工和劳动；熟悉一个邻居，也需要相遇。把时间调快，可以观察长期变化；暂停，则能仔细读一位居民的故事。

你的几个选择

你可以旁观，也可以改变小城的条件。每个选项都有资源或时间上的代价。

税率

调整居民工资中留下多少进入公共预算。更多税收有利于公共支出，也会减少居民拿到手的收入。

一起观察：金库、居民积蓄、食物价格。

福利

把有上限的日常公共预算，按设定比例用于帮助较贫困的居民。福利依赖真实的金库余额，无法无限发放。

一起观察：贫困居民的状态、金库的持续变化。

开放度

改变小城接纳外来居民的倾向。迁入还取决于生活状况和住房空位。

一起观察：住房容量、工作岗位、食物储备。

建设

住宅增加居住空间，农田与工坊扩大生产，公园和诊所为生活提供支持。选择建筑前，先看看资源与施工条件。

一起观察：建造成本、完工进度、新增设施的实际使用。

干预

降雨、干旱、节庆与补给可以直接改变一段时间里的条件。操作后的提示会说明结果与成本，城镇事件会留下记录。

试着只改变一种条件，再用几天的时间观察后续影响。

观察与操作

地图可以拖动和缩放。点开居民或建筑查看详情；名册适合找到具体的人，观察图层则帮助你从整座小城中看出差异。

把这座城留下

小城会尝试自动保存在当前浏览器的本地存储中。再次打开同一入口时，可以继续上次的城镇。关闭页面后，城镇不会在后台继续演变。

  1. 长期保留，导出一份档案。 导出后的 JSON 文件包含城镇状态，可以留在自己的文件夹中。

  2. 换浏览器或换设备，导入档案。 在线入口与本地文件、不同浏览器之间不会自动同步存档。

  3. 开始新城前，先留下旧城。 重置会替换当前的模拟。想比较两种走向，可以先导出同一个起点，再分别尝试。

这份记忆属于你

清理浏览器数据、使用无痕窗口或浏览器限制本地存储时，自动保存可能无法保留。可下载的城镇档案是更稳妥的备份。城镇模拟本身不需要外部模型、账号或 API 密钥。
