## Noto Serif SC 标题子集

- 文件：`noto-serif-sc-display.woff2`
- 字重：600
- 字符：栖川弦汐微光实验室河岸回声观察手记

- 授权文本来源：<https://github.com/google/fonts/blob/main/ofl/notoserifsc/OFL.txt>。

字体子集由 Google Fonts 的 `text` 请求生成，本项目不修改字形。字体以作品资源形式分发，不单独销售字体。

推荐声明：

```css
@font-face {
  font-family: 'Qichuan Serif';
  src: url('../assets/noto-serif-sc-display.woff2') format('woff2');
  font-style: normal;
  font-weight: 600;
  font-display: swap;
}
```

只有上述字形包含在标题字体中，正文应保留系统中文字体回退。
