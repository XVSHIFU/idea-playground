# 借一度 · Borrow a Degree

冬夜停电的小屋。你的体温是屋里唯一的火。

## 玩法

把手按在冷掉的东西上，它暖起来，你就冷下去。每一次传热都有一小部分散在空气里，所以你没法把热量无损地搬来搬去。

桌上有一杯冷茶、一只蜷着的猫、一盆将开的花，右侧是一扇结着冰花的窗。四件东西各自需要一笔净热量，暖好了就锁住，不再散热，还会给你一点回报——回报都会让后面每一步更便宜，所以先暖哪一样、暖到几成为止，是这一夜真正要算的事。

左边的火盆可以把手暖回来，但它不是无限的：柴随时间和取用一起烧掉，火会越烧越小，剩得不多时回温速度减半，而且只肯还你八成的热。手悬在空中也在散热，犹豫本身就有成本。

两种结局都写在同一张账本上：体温降到 30 度，你在椅子上睡着了；或者天亮了，窗还封着。

## 操作

| 动作 | 桌面 | 触屏 | 键盘 |
| --- | --- | --- | --- |
| 传热 / 回温 | 按住目标 | 按住目标 | Tab 或 ←/→ 选中，按住空格 |
| 换一样东西 | 直接按另一样 | 直接按另一样 | 松开空格后再 Tab |
| 重开一夜 | 右下「再守一夜」 | 同左 | R |
| 静音 | 右下「音效」 | 同左 | M |

按着的时候把指针拖到另一样东西上，热量会跟着改道。

## 实现要点

- `engine.js` 是纯逻辑：不碰 DOM、window、localStorage 和 AudioContext，可以被 Node 直接 `import`。`createGame(seed)` / `step(state, dt, input)` / `snapshot(state)` 都是确定性的——同样的种子与同样的输入序列，产出完全一样的结果（`engine.test.mjs` 里有对应用例）。
- `app.js` 负责 Canvas 2D 绘制、输入、Web Audio 合成音效、账本小票、`localStorage` 存档与无障碍播报。`index.html` / `style.css` 只有结构与样式。没有构建步骤，也没有任何外部依赖或 CDN 链接。
- 一次传热的守恒关系是严格的：`目标得到的净热 + 散在路上的损耗 = 你失去的热`。代码里损耗由 `spend − net` 直接得出，所以两者相加必然等于支出，浮点上也是精确的。
- 火盆是另一个守恒关系：`烧掉的柴 × 0.8 = 回到你身上的热`，剩下的两成从烟囱走了。
- 暖好的东西会锁定（`done` 之后既不吸热也不散热），茶与花的减损、猫的代谢减半都写在同一张 `REWARDS` 表里，改数值不用改逻辑。
- 窗上的冰要等茶、猫、花三样都暖好才肯化。没有这条规则，最优解会退化成「直接扑向最贵的窗」，前面三样就白设计了。
- 一直按着的时候，账本每 1.5 秒落一段，所以小票是一行行长出来的；连续的同一笔账（例如一直烤火）会合并成一行、时间显示成区间，否则纯烤火会把小票刷成几十行一样的字。松开或改道时会立刻把这一段落完。

### 数值表

单位：账本里的「度」是热量单位，`1 ℃ 体温 = 25 度热量`。四件东西的需求也是这个单位。

| 项目 | 数值 |
| --- | --- |
| 开局体温 | 37.0 ℃（热量 175 度） |
| 失败线 | 30.0 ℃ |
| 体温上限 | 38.0 ℃（热量 200 度） |
| 传热速度 | 每秒净热 7 度 |
| 转移损耗率 | 入夜 25%，天亮前升到 45%（夹在 12%–62% 之间） |
| 基础代谢 | 每秒 0.55 度（约 0.022 ℃/s） |
| 一夜长度 | 110 秒（账本上从 22:14 走到约 22:25） |
| 柴 | 360，自然烧掉 0.3/秒 |
| 火盆回温 | 每秒 10 度，返还率 80%，柴低于 30% 时速度减半 |
| 冷茶 | 净热 40 度 → 体温 +1.0 ℃，损耗率 −6% |
| 猫 | 净热 55 度 → 基础代谢减半 |
| 花 | 净热 70 度 → 体温 +2.0 ℃，损耗率 −5% |
| 窗上的冰 | 净热 95 度 → 天亮（需前三样都暖好） |

分数 = 剩余热量 × 0.8 + 剩余柴 × 0.7 + 剩余秒数 × 2。三星 ≥ 258，两星 ≥ 212，其余一星。三星不是「赢」就有的：40 条模拟路线的分数落在 194–275，258 以上要求贴着 30 度的失败线走。最好的一次记在 `localStorage` 的 `borrow-a-degree:best` 里。

## 本地打开

直接双击 `index.html` 只能看到结构——页面用的是 ES module，必须通过 HTTP 访问：

```sh
# 仓库根
npm start                 # 打开本机游乐场，从「氛围策略」里进
# 或者用一个临时静态服务器
npx serve borrow-a-degree
```

跑引擎测试：

```sh
node --test borrow-a-degree/engine.test.mjs
```

## 已知限制

- 没有音轨，只有事件音：茶与猫暖好、窗化开、结局各有一小段合成的音，火盆与柴见底有提示音。静音开关的状态单独存一条 `borrow-a-degree:sound`。
- 存档只记最好的一次成绩，不存进行中的一局；刷新即重开。
- 冰花、纸纹噪点由固定种子生成，每次一样，不随 `seed` 变化（`seed` 目前只影响初始抖动相位）。
- 画面是 Canvas 2D，不随窗口做精细重排：宽屏是一种构图，窄屏是纵向重排后的另一种构图，中间没有插值动画。
- 极窄（<320px）或极扁（横屏手机高 <400px）的窗口里，账本会收得很紧，只剩最近两行，需要点「账本」展开。
