# 链接生物 / 种子页

一个链接携带一只生物。纯前端，无外部字体、图片、运行时依赖或数据请求。

## 运行

直接打开 `index.html`，或在此目录执行 `npm start`，访问 http://127.0.0.1:4178 。无需 `npm install`。如端口被占用，在 PowerShell 中先设置 `$env:PORT=4180`。

跨设备分享时，把 `index.html`、`style.css`、`genes.js`、`app.js`、`favicon.svg` 放到任意静态网站。localhost / file 链接只适合本机；本站未部署到公网。

## 体验

- 移动指针：害羞的生物退缩，亲近的生物追随。点击、触摸、键盘 Enter / Space 都能互动。
- 繁殖：至少一项基因发生小幅变异，出现子代链接、变异说明和「去看看它」入口。
- 杂交：输入两个不同个体的链接，确保双亲都贡献基因后再突变。
- 命名：写入当前链接；谱系保存最近 80 只，含亲代关系、是否观察和陪伴记忆。
- 环境：本地时间影响体色与呼吸；窄屏轻微改变体态；语言轻微改变节奏。可以用环境模拟器比较，基因保持不变。
- 点击陪伴会提高本地亲近记忆，繁殖时部分写入子代 `e` 参数。

## 基因格式

hash 中 `v=1` 为版本，`id` 为个体标识。六项基因：`h` 色相 0–359、`s` 体态 0–100、`l` 肢体 2–6、`r` 节奏 0–100、`c` 亲和 0–100、`m` 突变率 1–30。`g` 是代数，`p` 是最多两个亲代 ID，`e` 是继承的陪伴记忆，`n` 是名字。

形态由基因确定，SVG 实时生成。环境不会重写 URL。孩子携带直接亲代 ID；完整祖先记录仅保存在产生过记录的设备，链接本身不携带无限谱系。最多记录 80 只，超出后淘汰最久未访问的记录。

## 验证与修改

`npm test` 运行 Node 内置测试，覆盖 URL 往返、非法基因、千代繁殖范围和双亲遗传。页面脚本为普通 defer 脚本，支持直接打开本地 HTML。

浏览器回归脚本为 `tests/browser.cjs`，需要已安装的 Microsoft Edge 与 `@playwright/test`。启动预览服务后运行；可用 `PLAYWRIGHT_PATH` 指向已有的 Playwright 安装，不属于页面的运行依赖。截图保存在 `test-results`。

- `genes.js`：解析、验证、繁殖、杂交。
- `app.js`：表现型、互动、历史记录与分享。
- `style.css`：响应式布局和动效，遵循减少动态效果设置。
- `server.cjs`：仅供本地预览的静态服务器，绑定回环地址。

浏览器禁用存储时会提示降级；剪贴板不可用时选中链接供手动复制。没有后端同步。
