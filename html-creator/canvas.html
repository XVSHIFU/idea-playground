01 · WHY为什么要把进程交给 systemd

在终端里启动一条命令很容易，难的是让它在重启后自动回来、异常时留下线索，并且始终以合适的权限运行。systemd 做的并不是“替你执行命令”这么简单，它把服务的生命周期变成了一份可以阅读、复现和审计的声明。

一份好的 unit 文件，应该让后来的人一眼回答三个问题：它依赖什么、如何启动、失败后怎么办。先从最小版本开始，再根据真实故障补齐约束，往往比复制一份巨大模板更可靠。

先把服务跑通，再逐步加固

本例使用 Python 自带的静态服务器，重点是理解 unit 的结构。生产环境请替换为真实进程，并明确工作目录、用户和资源限制。

02 · UNIT写下第一份 unit 文件

自定义服务通常放在 /etc/systemd/system。这是一条清晰的边界：软件包提供的 unit 属于系统，自己维护的服务属于你。

/etc/systemd/system/notes.service
[Unit]
Description=Notes preview server
After=network.target

[Service]
Type=simple
User=notes
WorkingDirectory=/srv/notes
ExecStart=/usr/bin/python3 -m http.server 8080
Restart=on-failure

[Install]
WantedBy=multi-user.target

ExecStart 必须使用绝对路径。systemd 不会像交互式 Shell 那样读取你的别名或个人环境；这种克制恰好让服务行为更可预测。

03 · PRACTICE启动服务，也读懂它的状态

修改 unit 后，先让管理器重新载入配置。随后启用并立即启动服务。把这几条命令连成一条固定动作，可以减少“文件明明改了，行为却没变化”的困惑。

terminal
# 重新读取 unit，并立刻启用服务
sudo systemctl daemon-reload
sudo systemctl enable --now notes.service

# 查看当前状态与最近日志
systemctl status notes.service
journalctl -u notes.service -n 50 --no-pager

为什么 status 显示的日志不够完整？

systemctl status 只展示最近几行，适合快速判断。需要还原完整时间线时，使用 journalctl -u 服务名，再按时间范围缩小上下文。

04 · RELIABILITY让服务在失败时更有分寸

Restart=on-failure 不是“永不宕机”的开关。它只说明异常退出后是否重启；配合等待时间与启动频率限制，才能避免错误配置造成高速重启循环。

不要用重启掩盖真正的错误

如果服务反复失败，先用日志确认原因。重启策略应该帮助系统从偶发故障恢复，而不是让配置错误不断消耗资源。

  1. 限制身份。使用专用用户运行服务，不给它无关目录的写权限。
  2. 控制重启。给异常恢复留出间隔，并限制短时间内的启动次数。
  3. 收紧边界。确认程序可用后，再加入 NoNewPrivileges 等安全选项。

05 · CHECKLIST留下一条可以复用的排查路径

真正有价值的不是记住多少参数，而是遇到问题时知道先看哪里。先确认 unit 是否被重新载入，再看状态和日志，最后检查服务依赖的用户、目录与端口。

一份最短排查清单

运行 systemd-analyze verify 检查语法；用 systemctl status 确认退出码；用 journalctl -xeu 阅读上下文；最后以服务用户身份手动执行启动命令。

ISSUE 017 · AUTUMN LETTER

雨落下来之前

有些安静并不是空白，
只是世界正在把声音收好。

文字 / 林间·阅读约 4 分钟

下午四点，窗外的树突然翻了一个颜色。叶子的背面比正面更浅，风一吹，整条街便亮了一下。卖花的人开始收起门口的木牌，远处有人把晾着的床单从阳台上取下来。大家都知道雨要来了。

我没有关窗。潮湿的风进来，把桌上的纸吹起一个角。杯子里还剩一点已经凉掉的茶，屏幕上的句子停在中间，像一条走到河边的小路。

我们总在等待事情发生，
却很少留意它抵达以前的样子。

风先替雨说了话

雨真正落下来的时候，反而没有想象中喧闹。第一滴落在铁皮雨棚上，隔了几秒，第二滴才跟上。然后是第三滴，第四滴。城市一点点慢下来，像有人将唱片的转速调低。

我终于合上电脑，去把那杯凉茶倒掉。回来时，窗玻璃已经变得模糊。对面的灯一盏一盏亮起来，每一扇窗里都有不必讲给别人听的生活。

有那么一会儿，我什么也没有做。只是坐在桌边，看雨水沿着玻璃往下走。原来安静不是没有声音，而是所有声音都找到了自己的位置。

写在页边

今天不必把所有事情做完。给一场雨留一点时间，也给自己留一点。
