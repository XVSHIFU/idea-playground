# 圆野 Roundland

一座没有方块的微缩岛屿。漫游、捏山、挖湖、种树，让小岛长成你喜欢的模样。

## 打开

- 在仓库根运行 `npm start`，从游乐场入口选择「圆野 Roundland」。
- 也可以直接双击本目录的 `index.html`。这是单文件 HTML，无需安装依赖或编译。
- 需要支持 WebGL 的浏览器，并联网从 CDN 加载固定版本 Three.js 0.160.0。

## 操作

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 漫游 | WASD / 方向键，Shift 奔跑 |
| 切换地形编辑 | E，编辑期间暂停角色移动 |
| 堆高 / 挖低 | 左键 / 右键，支持按住拖动 |
| 抚平地面 | Shift + 左键，或选择抚平笔刷 |
| 调整笔刷 | 面板滑块，或 `[` / `]` |
| 撤销 / 重做 | Ctrl / ⌘ + Z，Ctrl / ⌘ + Shift + Z |
| 种树 / 置石 | 底部工具或数字键 3 / 4，左键放置、右键移除 |
| 旋转视角 | 漫游时左键拖动；编辑时中键拖动 |
| 缩放 / 回到起点 | 滚轮 / R |

左侧面板支持更换种子、描边开关、跟随 / 自转、时间滑块和自动昼夜。触屏可使用方向按钮，并先选择隆起 / 挖低笔刷再操作地形。

## 存档

点击「保存小岛」将地形、植被、角色位置和时间保存在当前浏览器；点击「读取存档」恢复。换岛前会保存当前岛。

存储键为 `roundland-world-v1`，不会清空其他作品的数据。本地、GitHub Pages 和其他托管地址之间的存档不会自动互通。

## 实现与接入

连续 Perlin 噪声地形、非索引面着色、三阶 Toon 光照、反向外壳描边；共享顶点高度配合高斯笔刷和插值，保持编辑时的面片一致。重复植被使用实例化绘制。

公开资源仅有 `index.html`。`integration.json`、本说明和工作区文件属于开发资料，不进入 Pages 产物。网页无需后端，也不依赖本机服务端口。

调整接入信息后，在仓库根重新登记：

```sh
npm run project:add -- roundland --enable
npm run check
npm test
npm run build
```
