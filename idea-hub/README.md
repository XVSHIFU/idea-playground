# 小创意游乐场

本项目小创意的统一入口。双击 **启动.cmd**，打开 <http://127.0.0.1:4200>；需要 Node.js 18+，无需 npm install。命令行使用 `npm start`。双击 **停止.cmd** 可停止启动器创建的服务；命令行启动用 Ctrl+C。

用 `idea-hub.code-workspace` 打开入口独立工作区。所有项目现已整理到上级 `idea-playground` Git 仓库，各作品仍与本目录相邻。总工作区、静态发布和初始化命令见 [根 README](../README.md)。

点击作品后，在新标签页进入。服务按需监听各作品的本机端口，只提供目录中明确允许的公开资源，不执行其他项目代码。四个已有服务的端口保持原值；浏览器配置、协议、域名和端口相同才会沿用原有存档。以前用 file:// 或 localhost 打开的记录不会自动迁移到 127.0.0.1。新分配的 4191 / 4192 端口以此目录为准。

端口已被占用时，入口检查页面标题是否符合该作品；匹配则复用，无法匹配则显示错误。停止入口不会停止其他会话单独运行的服务。当前所有服务仅监听 127.0.0.1，尚未发布公网。

## 其他会话提供什么

无需贴源码。可以把下面这段发给各项目会话，让它填好后交回来：

> 请为「小创意游乐场」提供接入信息：项目目录、展示名称、一句话简介、不剧透的首次操作提示、可用入口文件或 URL、运行/构建命令及端口、公开静态文件/目录、存储与多标签页/弹窗/iframe 等限制。请注明当前是否可玩、正在改动的入口，以及是否有可用截图。不要重构项目或替主入口改代码。

推荐按 [统一接入说明](../docs/ADDING_PROJECTS.md) 使用根目录的 `project:new` / `project:add` 命令维护 `projects.json`，修改后重启入口。`enabled: false` 表示草稿，不显示也不构建。`required` 决定主入口是否可用，`fallback` 是未齐备时的可用替代入口；`identity` 必须出现在已有服务的 HTML title 中，用于端口冲突时的基本识别。`files` 精确列出可公开文件，`publicDirectories` 仅列可整体公开的资源目录，禁止放项目根目录。此接入方式适用于当前纯静态项目；未来有后端、登录、环境变量的项目需先提供运行接口，不能直接套用。

预览图来自各项目实际页面，放在 `public/previews/`，不是实时画面；项目变化后可运行 `node tools/capture.mjs` 更新（需先启动入口，并提供 Playwright，脚本默认复用相邻 protocol-zoo 的开发依赖）。`.impeccable/` 与测试文件只用于开发，不向浏览器公开。

## 验证

`npm test` 检查静态资源边界、按需启动、回退入口与端口冲突。`node tools/verify.cjs` 使用本机 Edge 和相邻项目的 Playwright，检查筛选、搜索、随机进入、新标签页、七个入口资源与桌面/手机布局。
