# 熄灯人 · The Last Lamp

你一盏一盏熄掉镇上的灯，把全镇人哄睡，天亮才肯来。

一座悬浮的深夜小镇，一条斜街七户人家。走进去，拉上窗帘、拽一下灯绳、把被角拉过肩膀，再用手掌把皱起的被面抚平。每户的 `sleep` 只走四档：0 → 0.33（关窗）→ 0.66（熄灯）→ 1.0（盖好被子、抚平褶皱）。七户都睡了，太阳才从山脊后面升起来。

## 运行方式

本作使用 ES Module + importmap 加载 `three@0.160.0`，**不能直接双击用 `file://` 打开**（浏览器会拦截本地模块）。请用任意静态服务器：

```bash
# 在仓库根目录执行其一：
python3 -m http.server 8080
# 或
npx serve .
```

然后打开 `http://localhost:8080/last-lamp/`。

- `index.html` — 游戏本体（单文件，无需构建）
- `shared.js` — 从《归途灯火》复制来的自包含 NPR 工具副本：种子化 PRNG、Perlin、3 阶 Toon gradientMap、反向外壳描边、弹簧与插值函数。本作只追加了几个纯数学工具，不改动其他作品的副本。

## 操作

| 操作 | 方式 |
|---|---|
| 走路 | 点地面 / 点某户门廊；移动端 tap |
| 关窗 | 按住窗帘向左下拖到底（8° 死区，到位回弹） |
| 熄灯 | 等灯绳静止（摆幅 < 0.15），按住绳球下拉 |
| 盖被 | 按住被角向上拖过肩膀；拖速 > 400px/s 会掀翻 |
| 抚平 | 手掌（指针）贴在黑被面上来回拖，接触半径 26px |
| 带门 | 按住门板推到底；不关门，起风时灯会重亮 |
| 重开本关 | `空格` / 底部「重来」 |
| 换镇子 | `R`（种子化，同种子同布局） |
| 音效 / 描边 | `M` / `O` |
| 取消拖拽 | `Esc`（移动端长按 0.76s 也可取消） |
| 视角 | 右键拖拽旋转（极角 35°–70°）、滚轮缩放、面板「自转」 |
| 关卡 | 左下面板下拉：8 个手工夜 + 无尽夜 |

## 关卡

1. **第一户** 3 户 / 300s — 教学
2. **睡不着的老先生** 4 户 / 320s — 失眠户要抚平两遍
3. **怕黑的孩子** 4 户 / 320s — 必须先熄大灯，再熄床头小灯
4. **猫在灯绳上** 5 户 / 340s — 猫蹲着的那户拉不动灯绳，先点猫把它引开
5. **风从西边来** 5 户 / 340s — 40s 起风，没关好的门会让窗帘被掀起、灯重亮
6. **二楼的人** 6 户 / 360s — 两户住楼上，需走外楼梯
7. **整条街** 7 户 / 400s — 全机制
8. **最后一扇窗** 7 户 / 420s — 最后一户的窗只能拉到留一条缝

无尽夜：随机 3–7 户、随机居民与风，预算 60s/户，记录最短天亮用时（`last-lamp:best`）。

## 技术要点

- **非体素低多边形**：地形用环状网格 + Perlin 起伏，`toNonIndexed()` 后按面着色、`computeVertexNormals()` 得清脆切面；房屋、家具、道具全部程序化几何，无任何外部模型 / 贴图。
- **全局 Toon**：`MeshToonMaterial` + Canvas 生成的 3 阶灰度 gradientMap（NearestFilter）。
- **反向外壳描边**：沿平滑法线膨胀 + BackSide 近黑，覆盖 7 户本体与坡屋顶、主角、猫、树、井、灯柱、篱笆，可用 `O` 开关。
- **合批与实例化**：静态主体 / 室内 / 道具各合并成 1 个顶点色网格；门、窗帘、灯绳、住户用 4 个 `InstancedMesh` 逐帧写矩阵；窗光 / 灯芯 / 街道灯用 1 个颜色批次按户改色。全场约 30 个 draw call。
- **交互**：窗 = 死区 + 弹簧；灯绳 = 单摆（阻尼 0.88/125ms），摆幅参与「可拉」判定；被子 = 9 个高斯核高度场，只在该户被拖拽时写 BufferGeometry。
- **第二表达层**：窗光三档（`#F2B45C → #C98A4B → #2A3A5E`，0.8s 插值）、住户坐→躺、月光变淡影子变长、呼吸声周期 3.2→5.5s 且按距离衰减、暖色像素量 = 还亮着的户数。
- **种子化**：所有随机走 `PRNG(seed)`，`R` 换种子可复现同一座镇子。

## 关于音频

规范允许优先尝试 `https://o.xbottle.top/mcsounds/` 的 MC 音效，失败回退 WebAudio 合成。为保证**零 console error**（离线或跨域请求会污染控制台），本作**有意不发起网络请求**，全部使用 WebAudio 合成：木框咔哒、灯芯叮、布料沙、脚步、呼气、日出和弦、猫叫；另有可关的呼吸层与风声层。

## 已知限制

- 需要经 HTTP 打开；`file://` 直开会被模块策略拦截。
- 二楼户型用外部楼梯 + 阳台表现「上楼」，没有做室内逐级楼梯动画。
- 猫的捣乱、风的阵风间隔用关卡的种子随机决定；同一关同一夜会复现。
- 移动端竖屏视野较窄，镜头会随角色轻微平移；可双指缩放 / 旋转。
