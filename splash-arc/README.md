# 投掷力学 · Splash Arc

你把喷溅药水掷向岛屿，染出冰面、蜂蜜与弹床——地形即物理，抛物线即答案。一座正午糖果色的微缩岛，信使小人在你铺出的地面上滑行、攀高、弹跳，把包裹送到收货图腾。

## 运行方式

本作使用 ES Module + importmap 加载 `three@0.160.0`，**不能直接双击用 `file://` 打开**（浏览器会拦截本地模块）。请用任意静态服务器，在仓库根目录执行：

```bash
python3 -m http.server 8080
# 或 npx serve .
```

然后打开 `http://localhost:8080/splash-arc/index.html`。仓库根也有 `npm start`（主入口，端口 4200）。

- `index.html` — 游戏本体（单文件入口，无需构建）
- `shared.js` — 复用的 NPR / Toon 工具：种子化 PRNG、Perlin 噪声、3 阶 Toon gradientMap、反向外壳描边、弹簧

## 操作

| 操作 | 方式 |
|---|---|
| 选药水 | 底部工具栏点选，或按 `1` 冰霜 / `2` 蜂蜜 / `3` 弹跳 |
| 投掷 | 在地面上按住蓄力（0–800ms，越久越远），拖动瞄准，松手掷出 |
| 出发 / 召回 | 底部主按钮，或 `Enter` |
| 重置本关 | `空格` |
| 换种子（随机邮路） | `R` |
| 取消蓄力 / 关帮助 | `Esc` |
| 自转 / 描边 / 音效 / 帮助 | 左上 Neo-Brutalism 面板 |

## 三种地面

- **冰霜（蓝）**：信使踩上去后沿原方向滑行，直到离开冰面或撞到障碍。
- **蜂蜜（黄）**：信使进入即停住；蜂蜜格可安全攀上 1 格高差（平时不可通行）。
- **弹跳（橙）**：信使踩上去后向前弹跳 3 格，可飞越壕沟。

药水有限，同格重复染色会覆盖；落在壕沟或水面上则白费一瓶。

## 关卡

8 关手工关卡（第一单 → 冰面快递 → 蜂蜜阶梯 → 弹床峡谷 → 双阶高地 → 蜂与冰 → 双沟飞越 → 正午邮路），难度递进为「单一规则 → 组合规则 → 时序规划」；外加 PRNG 生成的「随机邮路」程序化模式，会验证可解并记录最少投掷数（localStorage，键前缀 `splash-arc:`）。

## 技术要点

- **糖果亮色正午**：非体素低多边形浮岛，`PlaneGeometry` 细分 + Perlin 噪声起伏，`toNonIndexed()` 后 `computeVertexNormals()` 得清脆面着色。
- **全局 Toon**：`MeshToonMaterial` + Canvas 生成的 3 阶灰度 gradientMap（NearestFilter），哑光粘土质感，不用霓虹。
- **反向外壳描边**：`addOutline` / `addInstancedOutline`，沿法线膨胀 + `BackSide` 黑色，可开关。
- **染色地面**：网格状态用 `InstancedMesh` + `instanceColor` 表达，波浪式逐格染色（60ms 间隔）。
- **物理**：投掷走真实抛体运动，预览虚线与实际落点同一套公式；滑行/粘滞/弹跳三条地面规则为离散网格判定，可预测。
- **正交等距相机** + `OrbitControls`（限制极角、禁穿地）；`DirectionalLight` 硬阴影 `PCFShadowMap` 2048。
- **第二表达层（不看 UI）**：剩余药水越少——信使背包越瘪、小屋烟色越灰、蓄力音高越低、溅射涟漪越「干」。

## 关于音频

统一使用 WebAudio 合成（蓄力上升音、投掷呼哨、溅射、冰面滑行、弹跳、粘滞、胜负音），不发起外部音效请求，避免离线环境下的 console 噪音。

## 已知限制

- 必须经由 HTTP 服务器运行，`file://` 直开会被模块策略拦截。
- 随机邮路模式保证可解，但难度波动大于手工关。
- 移动端已支持按住蓄力与滑动瞄准，极端窄屏下工具栏需横向滚动。
