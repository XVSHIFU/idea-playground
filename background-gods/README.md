# 后台诸神

一个关于注意力的多标签页小玩具。每个标签页里住着一个生命：你看着它，它积攒微光；你离开，它在暗时间里做梦。第一版按“安静的观察”展开，弱目标、少提示。

## 打开

Windows 安装 Node.js 18 或更高版本后，双击 **启动.cmd**。也可以在本目录运行：

```sh
npm start
```

访问 <http://127.0.0.1:4177>。普通使用不需要 `npm install`、账号或远端服务。通过启动脚本开启的后台服务可运行 `powershell -File stop.ps1` 停止；终端启动用 Ctrl+C 停止。

`background-gods.code-workspace` 是独立编辑器工作区，本目录也有独立 Git 仓库。所有实现与依赖都限制在此目录。

## 试着相处一分钟

1. 看着第一个生命，根须会随微光缓慢舒展。
2. 点“创生一个”，在新标签页停留至少 12 秒。
3. 切回原来的标签页，看看它的梦与变化。
4. 点“从我分叉”，新生命继承部分微光、颜色和一段记忆，随后独立演化。
5. 关闭一个标签页；若有合适的仍在线生命，约 2.2 秒后，它会收到一段回声和一半剩余微光。

两个仍在线的生命，各自达到 24 点微光并累计经历 12 秒暗时间，会看见一道门。这个条件只是一处小发现，不妨碍自由观察。

## 机制与边界

- 前台每秒增加 0.8 微光，上限 100；后台每秒消耗 0.06，每 12 秒产生一个梦及形态变化。频繁切换没有额外奖励。
- 每个生命有独立的 localStorage 记录，使用 BroadcastChannel 通知彼此；没有 BroadcastChannel 时通过 storage 事件互通。记录都在当前浏览器，不发送到服务器。
- 时间戳结算，不按定时器触发次数计时。切换、唤醒及正常心跳都会核对可见状态；长时间后台冻结也能在回来后补算。已显示的后台状态可能因浏览器节流而延迟。
- sessionStorage 保持当前生命身份；Web Locks 防止两个活标签共用同一身份。刷新在短暂宽限期内恢复同一个生命。新标签的 sessionStorage 若是原页的副本，就尝试自动分叉；明确的“从我分叉”按钮更可控。
- 普通网页无法绝对区分关闭、导航、很慢的刷新，也不能可靠收到强制退出事件。这里用 pagehide 和 2.2 秒宽限期表达“离去”：快速刷新撤销回声；过慢刷新可能已留下回声。突然退出时超过 90 秒未确认的记录显示“远处·未确认”，不会凭心跳缺失发放遗产。
- 不支持 Web Locks 的浏览器仍能玩，但每次加载都会新建或分叉，不能保证刷新连续性。推荐在同一浏览器配置的 Chrome/Edge 桌面标签页中体验；跨浏览器、跨隐私窗口、不同端口不互通。直接打开 `file://` 不受支持。
- 注意力按页面可见状态判断，多窗口同时可见时可能同时成长。固定标签页无法由普通网页可靠识别，因此没有单独的固定玩法。
- 手机支持自适应排版，标签页关闭与冻结行为因浏览器而异。减少动态效果偏好会停住呼吸动画。后台页面不持续绘制。

## 文件

- `index.html` / `style.css`：界面与响应式排版。
- `app.js`：标签页生命周期、同源通信、存储、Canvas 生命绘制。
- `engine.js`：与浏览器无关的时间结算、遗产幂等、分叉与门条件。
- `server.js`：仅监听 `127.0.0.1` 的静态文件服务。

## 验证

```sh
npm test
npm ci
# 另一个终端先运行 npm start
npm run test:browser
```

浏览器测试默认使用本机 Edge；可用环境变量 `BROWSER_EXE` 指定其他 Chromium 浏览器可执行文件。测试使用独立浏览器数据目录，并会临时打开可见窗口，以实际验证标签页可见状态。不会连接或操作日常浏览器配置。

测试覆盖时间差补算、梦境累计、分叉、遗产只领取一次、门条件，以及实际多标签切换、刷新、关闭、复制 sessionStorage 后的身份冲突、storage 通信降级、帮助入口、320/390/768/1440px 布局。原生“复制标签页”菜单操作本身未自动化；测试复现的是它复制 sessionStorage 后的初始化路径。截图保存在忽略提交的 `test-results/`。

开发时参考了个人实践知识库的开发协作偏好。生命周期依据：[Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)、[pagehide](https://developer.mozilla.org/en-US/docs/Web/API/Window/pagehide_event)。
