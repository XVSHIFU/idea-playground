# 协议动物园 · MOTH/0

一个纯本地通信实验。根据上一级目录的 `protocol_zoo.plan.md` 实现：从机械回显走向预测，让参与者的重复与打断改变后续通信。

## 运行

直接双击 **index.html**，无需安装依赖或启动服务器。支持现代 Edge、Chrome、Firefox 和 Safari。

也可以用 Node.js 18+ 启动本地服务器：

```sh
npm start
```

打开 http://127.0.0.1:4173 。服务器仅监听本机。端口被占用时，在 PowerShell 中运行 `$env:PORT=4174` 后重新启动。

## 第一次观察

1. 依次点击 `11 → 22 → 11 → 22`，每次等待回显后继续。
2. 最后一次回显后等待约 1.15 秒，MOTH/0 会主动发送 `11`。
3. 改发 `33`，约 1.05 秒后收到 `00`。
4. 点击「让它休息」，再点击「重新连接」，它会复现已经形成的 `11、22` 开场。
5. 也可以反复发送 `33`，将它塑造成新的习惯。

短串输入支持 `A0 FF` 或 `A0FF`，一次最多 8 个完整字节。快捷按钮直接发送。

## 已实现

- 具有毫秒经过时间、发送 / 接收方向和主动信号标记的通信记录。
- 确定性模式学习、延迟打断响应、休息后复现习惯。
- 暂停 / 继续：保留待发送事件的剩余延迟。
- 休息 / 重连：取消待发送事件，保留学习历史与开场。
- 重置：确认后清空记录、笔记、学习状态及计时器。
- 观察笔记与 TXT 导出，导出内容包括完整通信记录和笔记。
- 手机布局、键盘焦点、输入错误提示、减少动态效果偏好支持。

所有状态仅存在于当前页面内存中。**刷新、关闭页面会丢失本次观察**，需要保存时请先导出。长会话界面只展示最近 400 条记录，导出仍包含全部记录。没有服务器端学习、真实网络设备、随机情绪或生成式 AI。

## 开发与验证

```sh
npm test
npm ci
npm run test:browser
```

`npm test` 使用 Node 内置测试运行器，无需安装依赖。浏览器测试使用 Playwright 和本机已安装的 Microsoft Edge；也可设置 `BROWSER_CHANNEL=chrome` 使用本机 Chrome。测试截图与导出结果保存在被 Git 忽略的 `test-results/`。

- `engine.js`：无 DOM、无时钟的确定性生物模型。
- `app.js`：通信调度、暂停与休息、记录、笔记与导出。
- `style.css` / `index.html`：界面。
- `server.js`：可选的本地静态服务器。
- `tests/`：模型及浏览器流程测试。
- `MECHANICS.md`：完整规则，想自行探索时可暂不阅读。
