# 红石脉冲花园 · Redstone Pulse Garden

单文件 Three.js 逻辑小游戏：在节点预算内种植脉冲花、延迟蘑菇、反相苔藓和与门藤，点亮所有目标花苞。内置五个关卡。

## 打开

从游乐场主页进入，或用现代浏览器打开 `index.html`。无需构建；需要联网加载 CDN 上的 Three.js 0.160.0。也可以在仓库根运行 `npm start`，通过统一入口打开。

## 操作

- 从底部拖拽植物到苔藓印记；也可以先选卡片，再点击空槽。
- 点击脉冲花发射，右上角按钮同时发射所有源头。
- 右键或长按移除自行放置的植物，原有植物不可删除。
- 空格重置，R 更换装饰种子；拖动空地旋转。
- 面板可调整描边、自转、光照、信号速度和音效。

## 规则

相邻槽位自动连线，不连接对角。蘑菇收到信号后等待一拍；反相苔藓本拍没有输入时，下一拍发射。与门需要两个不同源头从不同入口在两拍内抵达，同源分叉不算双源。单颗信号不重复访问节点，每轮观察 24 拍，可以无限重试。

所有几何和音效均程序化生成，不依赖模型、贴图或音频文件。音频使用 WebAudio，首次交互后启用。无后端、密钥、持久存储或跨标签页通信。

## 验证

HTML 内模块已通过 Node.js 语法检查。根目录的 check、test 和 build 用于验证作品接入与发布资源；未实测移动端帧率及每帧 JS 耗时。
