# 咔哒，塌啦 · Click & Collapse

你拆掉由 MC 脚手架转译的榫木支架，边拆边接，把小陶兽完整送进软垫，获得精准拆解的痛快。

## 打开与操作

在仓库根执行 `npm start`，或在根目录运行 `python -m http.server 4310` 后访问 `http://localhost:4310/click-collapse/`。保留生成的工作区端口 4310。模块入口需要 HTTP/HTTPS，不支持 file:// 双击。Three.js 0.160.0、cannon-es 0.20.0 从 jsDelivr 加载，需要联网；无需后台、账号或密钥。

点朱红榫钉拆连接；按住已经松脱的板子把手拖动，松手或 Esc 释放。持板时不能同时拆钉。右键与滚轮观察，触屏可从空白起双指观察，或开启观察模式。空格重试，R 再拆一座。种子输入后回车重玩，复制按钮复制种子。所有关卡可以直接选择。

## 文件与实现

- `index.html`：界面、程序化几何、Toon、实例化描边、输入、合成音频和主循环。
- `shared.js`：固定 120Hz 刚体规则、连接登记、支撑遍历、限力托板、24 个结构、种子变换及两条见证输入。
- `integration.json`：独立公开资源只有上述两个文件。没有跨作品相对依赖。

PRNG、阻尼比弹簧及三阶灰度生成方法改写自仓库 `last-cast`，描边改为焊接法线加屏幕空间外壳，以保持缩放下的线宽。工具保存在本作代码中，未改动引用来源。源码没有外部模型、纹理或音效资源。

每颗钉的图边和实体约束在同一步删除。支撑仅控制对世界的固定状态，存续铰链不被删除。可见立柱是铰链与可拆连接的真实锚点。陶兽没有连接到托盘。手柄为最大 29.4N 的偏心弹簧力，目标移动速度不超过 3.2 世界单位/秒，不重置刚体姿态或速度。

损伤使用碰撞前的法向相对速度和两刚体的有效平移质量，单次动能阈值为 7.6；软垫吸收阈值 42。没有累计血条。每步先检查全部损伤，之后才检查真实软垫接触、内圈与净空。结果一经锁定不反转。碰撞形状是简单代理；不是完整工程结构模拟。MC 仅提供拆支撑造成依赖部分失撑的因果灵感。

`click-collapse:progress` 保存种子通过记录和个人最少拆除次数；`click-collapse:last` 保存重玩位置。不会清理其他作品存储。种子仅选择验证过的模板及绕竖轴的四分之一转，非任意随机木塔。相同种子初态相同；不保证跨浏览器浮点结果逐位一致。
