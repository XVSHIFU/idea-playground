# 最后一竿 · The Last Cast

你用钓鱼竿钓回逐渐沉没的老屋里的旧物，在最后一扇窗消失前，把一份不舍带上船。

## 打开与操作

在总仓库运行 `npm start`，从游乐场打开本作。独立预览可在仓库运行 `python -m http.server 8000`，访问 `/last-cast/`。使用 HTTP(S)，不使用 file://。

按住可见旧物瞄准，松手抛钩，挂钩后再次点击收竿。WASD / 方向键移船，右键观察，滚轮缩放。触屏切换底部“垂钓 / 移船”，移船用摇杆，双指观察，挂钩后使用收竿按钮。物件必须落入船舱并停稳，掠过船上方不算取回。

Space 重试同一种子，R 换种子，P 暂停，M 静音，Esc 取消或回钩，H 隐藏 / 恢复界面。隐藏界面后触屏仍有恢复按钮。切后台自动暂停，返回后手动继续。关卡选择和“漂来的旧日”在航行手记中。

每局 90 秒有效模拟时间。取回主物件即可获得成功条件，时间结束或六件物品全部取回时离岸。失败不会扣除任何资源。存档仅使用 `last-cast:` 前缀，记录种子、声音偏好与该种子的最快主物件用时 / 成功局最多带回件数。

## 文件与发布

- `index.html`：单 HTML 入口与内联样式，Three.js 0.160.0 importmap。
- `app.js`：程序化场景、输入、呈现、音频和界面。
- `shared.js`：本地随作品发布的 NPR 工具；从 `lantern-way/shared.js` 复用三阶 Canvas 渐变与弹簧思路，描边改为位置焊接后计算平滑法线，避免逐面外扩裂缝。不改动原作。
- `physics.js`：不依赖渲染器的物理、关卡数组、垂钓状态机与路线验证。
- `physics.test.mjs` / `browser.test.cjs`：开发验证，不发布。
- `integration.json` / `last-cast.code-workspace`：接入资料与工具分配的端口 4308。

公开白名单仅有 HTML 和三个运行脚本，不发布说明、测试或开发环境。构建后路径为 `dist/projects/last-cast/`。无外部模型、贴图、字体、图片或音频请求；需要 CDN 加载 Three.js 与同版本 addons。资源失败显示错误提示，不用静态海报冒充游戏。未追加入口预览图。

## 物理与参数

以一船宽为一世界单位。固定步长 1/120 秒，最多追赶 7 步；长帧超额时间不补算。重力 9.8，收竿固定冲量 6.4，质量 0.8 / 1.0 / 1.2。竿尖最终高度调整为水面上 1.35，用同一高度改善高窗向下牵引压住地板的问题，不按目标改力。抛钩水平速度基准 6.8，最大水平射程 4，最大初速 11，前摇 160ms，空钩回收 240ms。

鱼钩逐段扫掠球体与建筑碰撞体，预览与正式判定调用同一逻辑。运动旧物每步按位移细分，单次位移不超过 0.025。旧物用少量球体组合处理窗框、墙、地板、船沿与承接面；旧物间使用包围球接触。使用简化浮力、阻尼和水平角速度，不是完整六自由度刚体系统。船保持固定船体朝向，移动改变牵引方位；没有船体转向模拟。

轻碰恢复系数 0.18；水阻 4.6/s，最大巡航速度约 0.82。落船要求真实承接面接触、位于舱内、相对速度小于 0.15、角速度小于 0.5，连续满足 350ms。通过后才以 280ms 整理到舱位。每次收竿只写入一次冲量，不自动修正轨迹或吸附终点；取消不能回滚已发生的运动。再次触水可重新挂钩。

表现弹簧保留当前值与速度：竿尖 response 240ms / ζ 0.65，人物前倾 500ms / ζ 0.9，船侧倾 650ms / ζ 0.85。UI 220ms cubic-bezier(.23,1,.32,1)。湿色按实际触水高度保留局部深色。屋内合成音按窗口覆盖率以 800ms 响应衰减与低通；音频权限失败不阻断玩法。

```sh
node --test last-cast/physics.test.mjs
npm run check
npm test
npm run build
node last-cast/browser.test.cjs
npm run verify:pages
```

浏览器脚本可用 `BROWSER_EXECUTABLE` 指定现有 Chromium，`LAST_CAST_OUTPUT` 指定临时验证目录。真实指针操作完成抛钩和取回；结算测试加速执行同一固定步模拟到截止时间，不声称人工等待了整局 90 秒。测试入口仅在 URL 带 `?test` 时开放。

## 真实限制

本作具备十二关和程序化模式的完整核心循环，但不是提示词全部细节均通过验收的版本：船体未转向，旧物仅模拟水平转动；手臂、湿色、水珠等表现做了简化；尚未逐项对所有手感响应时间与人工听感做测量。性能目标与全站验证仍有上述未完成项。已捕获真实触水后木马离开侧窗的运动帧；该截图对应的浏览器路线未完成最终落稳，不能勾选“指定画面在成功路线中验证”。不把普通首屏截图当作该帧。
