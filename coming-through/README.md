# 借过一下 · Coming Through

你牵起 MC 拴绳，把圆鼓鼓的小牛拉过立体晾衣场，在拉一拉、松一松的即时碰撞中获得一起玩闹的快乐。

当前版本是可继续验收的实现版本，**不是已完成全部验收的成品**。开发环境未完成浏览器真实交互验证，下面明确区分物理回放、资源检查和真人操作。发布状态以 GitHub Actions 实际结果为准。

## 运行与文件

- 入口：`index.html`；本地工具库、关卡和生产物理：`shared.js`。
- 单页无需构建。通过 HTTP/HTTPS 打开，不承诺 `file://` 双击运行。依赖固定 CDN 的 `three@0.160.0`、对应 OrbitControls/BufferGeometryUtils、`cannon-es@0.20.0`。
- 仓库根运行 `npm start`，从总入口进入；合入并行作品后按初始化工具的未占用端口规则分配 **4311**，工作区文件保留。
- Pages 子路径预览：根目录 `npm run build` 后 `npm run preview`，访问 `/idea-playground/projects/coming-through/`。
- `integration.json` 和 `idea-hub/projects.json` 已本地启用；公开清单仅 `index.html`、`shared.js`。README、测试和工作区不会发布。
- 存档仅使用 `coming-through:save`，保存选关、种子、通关和最少握绳次数，不清除其他作品存储。

## 操作

抓住陶红绳结拖动，松手解除人为牵引。抓绳时滚轮、Q/E 或右侧高度滑杆提降绳头。未抓绳时右键旋转、滚轮缩放；观察开关可锁定镜头。触屏主指拖绳、另一指调高度，未抓绳时双指观察。空格重试、R 生成种子段；成功提示不锁操作。

## 实现边界

- 固定步长 1/120 秒，每帧最多 6 步；牛是带躯干、鼻部、圆钝牛角及蹄子的复合刚体，胸前偏心挂点传递力与转矩。
- 20 段单向受拉约束；松弛时不施加推力。松手不重置节点、速度或接触，重抓从当前绳结状态接入。
- 绳段与有限圆杆/门框的整段最近点接触，使用重心权重 Jacobian，在同一求解器里协调两端点、绳长与牛体约束；没有永久绕杆标志。
- 握结速度限制 3.9 单位/秒，手部力上限 30N。几何和碰撞尺寸不随拉力缩小。
- 24 个命名布局，各有高位绕杆及低位牵引见证轨迹；种子模式选择这些布局的正向或整体镜像，没有现场求解等待。
- 成功检查躯干、鼻部、牛角、蹄子碰撞凸包的全部顶点是否越过出口平面。
- 三阶 Canvas 梯度、Toon 材质、独立平滑法线外扩描边，程序化几何和合成音效。Toon/描边/PRNG 从 `lantern-way/shared.js` 适配，已复制到本目录，不依赖其他作品文件。

## 已执行的检查

- 根 `npm run check`：通过。
- 根 `npm test`：7/7 通过。
- 根 `npm run build`：通过。
- `/idea-playground/` 前缀下入口、index.html、shared.js 返回 200；README 返回 404，公开范围检查通过（HTTP 检查，不是浏览器验证）。
- 物理回放：24 × 2 条路线 × 2 镜像，共 96 组合。整套初次 94/96；第 8 段支柱净空修正后，对该段四组合定向重测 4/4。其余关卡物理未变，因此最终组合覆盖 96/96。
- 另外检查：同种子初态及回放一致、松弛不能推牛、松手不传送绳结、立即重抓接入当前位置、中心越线不算通关。
- DOM/几何初始化冒烟：选关、重置、几何构建、主循环绘制准备通过。测试用了渲染器替身，**不证明 WebGL 画面正确，也不是真实指针操作**。
- 环境：Linux x86_64，Intel Xeon Platinum 8573C，Node v24.19.0。整套回放测得单物理步 p95 约 2.77ms；第 8 段定向重测约 1.70ms。它不包含 GPU、渲染或浏览器事件处理，**不能据此宣称主循环 p95 <3ms 或手机 ≥40fps**。

复现物理测试（本地准备上述两个固定版本的 ESM 文件）：

```sh
THREE_MODULE=/absolute/path/three.module.js \
CANNON_MODULE=/absolute/path/cannon-es.js \
node coming-through/tests/physics.mjs
```

可加 `TEST_LEVEL=8` 定向检查。测试只加载生产 `shared.js`，无替代通关逻辑；输出到 stdout，不向公开清单加入测试资源。

## 未通过或未实测

- `npm run verify:pages` 受阻：仓库指定浏览器包下载损坏；另行取得的 Chromium 134 在启动时被环境 Unix socket 权限拒绝。浏览器插件也无法访问隔离环境的 localhost，内嵌数据页预览被其 URL 安全策略拒绝。未绕过限制。
- 尚无桌面真实拖动/滚轮、手机双指分工、失焦/取消捕获的浏览器实测，尚无线上刷新/存档实测。
- 绳段约束存在瞬时数值伸长，最终通过路线中最高约 14.7%。固定的是本段约束目标长度；本实现尚未达到严格不可伸长验收，也未证明所有极端输入下完全无穿透。
- 24 段有完整选择/重试/种子及物理可解性回放，但六组关卡的精细差异尚未完整达到需求；尤其未做前后双椭圆门的专门递进。部分高位见证从门框外侧绕行，不能当作指定“斜挤门洞”截图路线已经完成。
- 布片目前由接触强度和轻摆驱动，不是独立布片接触模拟；鼻尖只有局部视觉压缩。
- “歪着也行”的指定截图帧未在真实浏览器中出现并捕获；无宣传图或虚构预览。
- 首屏 300ms、重试 200ms、输入 33ms、draw call <70、浏览器主循环及移动端帧率均未实测，不作达标保证。
- 首次交付时命令行无 GitHub 凭据，插件曾返回 `Unknown tool`；后续通过恢复的 GitHub 连接同步。没有修改部署设置或强推；发布记录以仓库 Actions 为准。
