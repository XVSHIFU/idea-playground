# 越抢越变形的拍卖会

三人同屏玩的黏土竞价原型：出价消耗一块材料，并将它留在正在争夺的作品上。愿望可以随作品改变，最后有效出价者带走整件东西。

## 打开

双击 **启动.cmd** 或 **index.html**，无需安装依赖、联网或构建。用 **clay-auction.code-workspace** 打开独立工作区。父目录不是 Git 仓库，因此建立独立目录，没有创建 Git worktree。

也可运行 `npm start`，打开 <http://127.0.0.1:4193>；需要 Node.js 18+，不需要 npm install，Ctrl+C 停止服务。服务仅监听本机，并只公开游戏所需的六个文件。

## 怎么玩

- 默认甲、乙、丙三人，每人五块泥；「另开一轮」设置名字、开场愿望与先手。
- 选部件，在台面上点一下，再旋转；也可按住台面自由画。部件必须接触底泥或已添加部件，才能确认出价。未确认可重捏，确认后不能撤回。
- 每次出价轮到下一位挑战者。领先者不用给自己加价；其他人退出或材料耗尽时，最后出价者获胜。全员未出价就退出则流拍。
- 「改主意」记录偏好变化。下方时间轴回看每次添加；回看时暂停出价，回到现在后继续。
- 落槌后取名，保存 SVG 作品图。当前一轮保存在当前浏览器，刷新恢复已确认动作；未确认草稿不保存。「另开一轮」会替换当前进度，旧局不会另存为图库。
- 请共用一台设备的同一个标签页。本机 file://、localhost 和 127.0.0.1 的存档互不保证通用。浏览器禁止存储时会提示；无在线同步、AI 对手或真实三维物理。

完整规则与可打印的实体试玩说明在 [rules.html](rules.html)。网页用二维泥条表达拼接，不计算黏土体积和承重。结算、接触阈值与泥条长度上限是本次补充的原型约定；乐趣、真实时长、先手优势及真实接缝稳定性尚未真人验证。

## 创意来源

用户提供五个点子：味觉套印、融化障碍赛、动作声音重配、变形拍卖、用静物变化叙事。本工作区仅展开第 4 个。

保留的交点：付出的东西必须留在被争夺的东西里面。颜色保留贡献痕迹；部件不能拆除，因此后来者必须回应旧结构；愿望没有计分奖励，不把自由偏好变成秘密任务。

用户示例为「浅碟的边 → 高柱 → 像提梁的拱 → 重新想要一个小篮子」。这是机制示例，游戏初始只有底泥，不预写这条发展路线。下一步实体试玩最值得观察的是：哪一块改变了人的偏好，以及接缝修改到什么程度才被认为是破坏。

## 开发

`engine.js` 为纯规则与几何检查；`app.js` 负责操作、显示、存档回放校验和导出；`style.css` 为响应式样式。

`npm test` 验证退出、耗尽、归属、连接合法性与存档。`npm run verify` 使用相邻 protocol-zoo 已安装的 Playwright 和本机 Edge，检查实际回合、刷新、导出与桌面/手机布局；可用 `CLAY_PLAYWRIGHT_MODULE` 指定其他 Playwright 路径。游戏本身不依赖这些测试工具。
