## 创作约定（包含答案）

分歧是系统从未形成跨应用的通用内容暂存区，而非计算机不能复制字节。文件、应用内部复用、收发邮件均存在。跨应用内容交接必须绑定发送方、接收方和格式，由双方确认；“暂存桌面”只是对仍在运行的来源应用的引用，不能独立保存或向任意接收方分发内容。

这让打印重录、定向交接协议、对无接收方文字传送的安全争论、人工转录服务和代际礼仪从同一规则自然产生。页面中不出现“这个世界没有复制粘贴”或通关揭晓。

## 五份档案与透露顺序

1. 1997 教程：打印网页，再用 Text Camera 录入邮件。荒诞但实用，先展示日常代价。
2. 2003 论坛：Text Teleportation 的争论。逐渐发现争论针对的是“内容能否先离开发送者、以后再决定给谁”。
3. 2001 手册：暂存桌面的边界。来源退出，纸签失效；纸签不是独立副本。
4. 2041 事故：可信原件与重录字段被错当成同一个对象；附件签名未被破解，系统却把出处核验当作支付字段授权。
5. 2043 讨论：定向交接已成熟，但两端确认仍支配社交与日常。普通人的抱怨补全文化后果。

建议入口顺序是教程→论坛→手册→事故→现代讨论，所有页面允许任意进入。重复线索为“接收方”“来源退出”“纸签不是正文”，分别进入技术、产品和日常语境。每页最多承担一个主要新线索，不设置搜集进度或谜底按钮。
