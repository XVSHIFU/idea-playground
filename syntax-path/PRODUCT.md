# 句法小径

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

用户要求 HTML。沿用独立工作区，以原生 HTML、CSS、JavaScript 制作可直接打开的静态体验，无构建步骤和外部运行依赖；这是本次实现选择。

## Product Purpose

把句法关系变成可以行走、返回和重连的空间。第一版承接 README 与 PLAYTEST 中两种候选分组，让参与者体验连接差异，并留下观察。

## Users

用户本人及受邀试玩的朋友。使用桌面或手机浏览器的设定为本次实现假设。

## Capabilities and Constraints

同一句话的两种连接方式、逐步行走、侧室开合、结构对比与本地记录。关系图使用预设示例，不宣称能自动分析任意句子。身体与纸面体验不能由屏幕验证代替。学习效果未经验证。

## Brand Commitments

名称为句法小径；核心意象是主廊、侧室、折痕与门槛。

## Evidence on Hand

README.md 保存用户创意摘要，PLAYTEST.md 保存纸面实验。无真人试玩证据；不生成虚构结果。
