# 句法小径

把一句话折成可走建筑。主句成为主廊，修饰语和从句成为侧室，连接词与标点成为铰链和停顿平台。用手指沿路径走，再读一次原句，观察哪里需要进入、回望或停顿。

当前提供可直接打开的 HTML 互动版，以及可照做的纸面实验说明。网页操作已通过本机 Edge 自动化检查；尚未进行实体制作和真人试玩。空间映射是设计约定，不是语言学结论；是否帮助理解句子、是否好玩，都有待观察。

## HTML 版怎么玩

点击“向前走”，跟随橙色小珠走过主廊、进入侧室，再回到原接点。用“退一步”回看，用“回到入口”重走；焦点不在表单或按钮时，也可按键盘左右方向键。小珠移动期间会暂时禁用前进和后退，避免连续操作跳过接点；系统开启减少动态效果时直接切换位置。

切换 A / B 会把小珠放回入口，侧室分别连接共用门厅或老师房间，绿色范围和句子高亮随之变化。“折起纸面”切换房间的平面与立体示意，“隐去词语”只隐藏图中的房间标签；旁边说明仍可阅读。桌面显示横向主廊，手机显示纵向主廊。窄屏图中副标签较小，相同信息可在行走说明中阅读。

在“留下一次回望”中，分别记录两种读法的自然度与感受。笔记和走完状态自动保存在当前浏览器的 localStorage；行走位置不跨刷新恢复。浏览器限制存储时页面会提示，仍可导出两份观察为 Markdown。`file://`、不同服务地址与不同浏览器的记录不保证共享，移动目录前建议先导出。

“打印这一页”调用浏览器打印，输出当前结构和当前选择的笔记；要完整保留 A / B 两份记录，用“导出两份观察”。网页展示的是预设关系，不能自动解析任意句子，也不模拟真实折纸的力学。

## 体验的核心

读起来顺的句子，走起来可能很深。一个“的”可以像一扇门，把一组词圈进同一个空间；嵌套可以变成房间里的房间；连接位置变化时，同一组词可能出现不同的空间关系。

参与者先选句子并说清拟比较的解释，再画主路径、做侧室、折起门槛。手指进入侧室后必须沿原路返回接入点，才能继续主廊。走完重新读句子，记录哪些空间动作对应了阅读感受，哪些只是纸张造成的麻烦。

朋友也可以先看模型、后看句子，尝试描述“哪个房间属于哪个房间”。猜中句子不是必需的胜利条件；更值得观察的是，连接关系能否被感到。

## 暂定映射

| 句子关系 | 空间设想 | 首轮如何使用 |
| --- | --- | --- |
| 主句 | 连续主廊 | 保留一条从入口到出口的路线 |
| 主语、谓语、宾语 | 入口庭院、中央通道、尽头房间 | 用简化短语标记，不追求完整分析 |
| 修饰语、从句 | 侧室、夹层、地下空间 | 先只做能返回主廊的侧室 |
| 连接词、标点、虚词 | 铰链、门槛、停顿平台 | 按具体关系设计，不规定一个词永远对应一种机关 |
| 依存距离 | 路径长度 | 保留为后续假设；首轮不把纸上厘米数当句法测量 |
| 嵌套深度 | 房间套房间、逐层翻折 | 等一个侧室能够走通后再增加 |
| 不同解释 | 同一组词改变接入位置或分组 | 先试读解释，再比较模型 |
| 山折与谷折 | 开关入口、改变进入方向 | 折痕必须改变可走关系，单纯装饰不算机制 |

这些映射允许修改。首轮沿同一套规则比较两个模型，避免同时改变颜色、房间大小和通行规则，让人无法判断差异来自哪里。

## 例句的边界

原提案使用“我看见拿着望远镜的女孩”，希望比较“女孩拿着望远镜”和“我拿着望远镜看女孩”。保留这一创意来源，但第二种解释能否自然从原句读出尚未核实，不能先把它写成已经成立的双重句法分析。改写句子后得到两个不同意思，也不能据此证明原句有歧义。

首轮改用候选句“我看见了学生的老师和朋友”，比较“学生的”覆盖“老师和朋友”与只覆盖“老师”两种分组。它仍需参与者先试读；后一种分组不指定朋友属于谁。若参与者只接受一种解释，就记录结果并换句，不强迫他们接受设计者的读法。具体构造见实验说明。

## 继续探索什么

先看侧室是否让人注意到“修饰谁”，以及进入、返回是否带来值得描述的体验。有效后，再尝试更深的嵌套、夹层与翻面。

否定、时态、回指、被动可以探索镜面、暗室、回望窗或旋转门，但这些都只是候选，不预先做成完整密码表。需要区分三件事：模型连接是否一致、参与者是否理解、参与者是否觉得有趣；前一项成立并不能证明后两项。
