# 归途灯火 · Lantern Way

在天黑前点起有限的火把，让迷路的小人走回岛中央的床。

## 运行

在本目录执行 `python -m http.server 8080`，浏览器打开 http://localhost:8080/ 。无需安装依赖或构建。不要直接通过 `file://` 双击打开：浏览器会限制共享 ES 模块。运行需要联网加载 Three.js 0.160.0 CDN。

项目只有三个文件：`index.html` 承载全部界面与游戏；`shared.js` 提供种子 PRNG、Perlin 噪声、Canvas 三阶 Toon 材质、平滑法线外壳描边和弹簧；本文件说明运行与验证。仓库原先没有 shared/ 或 shared.js，因此在本子目录新建。全部模型由代码生成，没有外部模型或贴图。

## 玩

- 第一支火把落下，旅程和倒计时开始；此前可以观察小岛。
- 点按地面放置，拖动连续铺设。右键或长按 480ms 收回火把。
- 按住「快进」或 Shift，游戏时间、行走和恐惧变化同时变为 1.6 倍。
- 双指缩放/环绕，鼠标滚轮缩放，中键或 Alt 拖动环绕。
- 空格重置；R 切换装饰种子；Esc 收起预览圈，下次点按恢复。
- 日夜滑块切换为手动时间，拖到最右仍会失败；「恢复自动」继续计时。
- 可以暂停、切换描边、自转、音效、照亮半径；移动端设置面板默认折叠。
- 无尽夜路记录通过夜数，存储键 `lantern-way-best`。禁用本地存储不影响游玩。

## 关卡与规则

12 个手工配置的丘陵、河谷、森林、断崖、碎石关卡，之后是种子化无尽模式。床在中心；深色河谷和断崖区域不可穿过，植被不阻挡。短路线可以少放灯，沿外侧绕行并增加光圈重叠能提供更多安全余量。关卡数据集中在 `LEVELS`；预算、时限、起点、障碍椭圆均可编辑。

A* 在 41×41 网格上计算，黑暗代价为 90，禁止斜穿障碍拐角。路径允许规划未来黑暗段，但移动前再次检查下一步是否有光，所以他会在光的边缘等待。火把变化触发重新寻路，间隔至少 0.2 秒。床边有很小的安全区域。

恐惧在黑暗中累积、光中缓解；体态与步速直接受影响，身体颜色用保留速度的弹簧缓和，另有拉长的情绪影子和合成心跳。不显示恐惧数值。满恐惧或天黑失败，抵家后爬上床、镜头轻推、三音上行，均可重试。

步速按每关的地形路线和时限匹配，使顺利铺灯的默认流程接近落日前抵家。最后几秒，太阳只剩上缘、长影和暖橙灯路真实存在于场景中；不同操作会改变实际抵家时刻，并非强制播放截图。

## 渲染与音频

圆盘化 PlaneGeometry 保存 indexed 源，再转 non-indexed 计算平面法线。薄土层与圆润岩底连续收口。主要几何使用 MeshToonMaterial + Canvas 三阶灰度 gradientMap；外壳沿合并平滑法线膨胀，以 BackSide 绘制。植被合批，火把 InstancedMesh，单个无阴影 PointLight 跟随靠近小人的火把。光照颜色用空间桶定位，只更新受影响的地形顶点；火把点燃 0.4 秒波前扩张、熄灭 0.2 秒回退。

音效默认关闭，可开启。首次交互初始化 AudioContext；已查询指定 MC 音效站，火焰使用其 `block.fire.ambient` 音效，地址来自该站 API。加载超时 2.5 秒、CORS 或解码失败会静默回退到 WebAudio 合成。木击、熄灭、胜负音与心跳由 WebAudio 合成，无音频文件随项目分发。

## 验证结果与边界

- 已通过 HTML 脚本闭合、importmap JSON、唯一 ID、事件目标引用和 Node ES 模块语法检查。
- 使用 Three.js 0.160.0 在 Node 中实例化了 12 关全部地形、装饰、角色、床与火把，检查几何属性无 NaN/Infinity；外壳与合批正常生成。
- 12 关均通过 A* 连通性、预算内灯光覆盖及逐步行走抵家模拟。检查用 4–5 支灯可覆盖路线，预算为 6–8 支。另有 128 个无尽种子通过灯光覆盖与抵家模拟；无尽模式参数限定为单个不封岛的中央障碍。
- 从场景对象与阴影投射物估算最大约 67 draw calls；`?debug` 可显示实际 draw calls、平均 JS 帧耗时和 FPS。
- **浏览器实测未完成**：当前受管预览环境报 `bwrap: Can't mount proc on /newroot/proc: Operation not permitted`。因此不能宣称已验证零浏览器 console error、真机触控、40fps 或 JS <3ms/帧。以上性能数值中 67 是估算，不是 GPU 实测。
- 需要现代 WebGL 浏览器及可访问的 CDN；WebGL 创建失败显示友好提示。恐惧影子为贴地的风格化平面，陡坡可能有轻微穿插；不是精确地形投影。
- 为遵守本次「不覆盖仓库已有文件」，仅新增 `lantern-way/`，未修改 `idea-hub/projects.json`。因此不会自动出现在现有总入口或其 Pages 构建清单中；子目录可独立静态托管。
