# 归途灯火 · Lantern Way

你点起火把，让迷路的小人在天黑前走回家。一张起伏的低多边形浮岛，黄昏开始，倒计时里放置有限火把，照亮一条路，引小人走到岛中央的床。火把是保护，时间是压力，恐惧是第二表达层。

## 运行方式

本作使用 ES Module + importmap 加载 `three@0.160.0`，**不能直接双击用 `file://` 打开**（浏览器会拦截本地模块）。请用任意静态服务器：

```bash
# 在项目根目录执行其一：
python3 -m http.server 8080
# 或
npx serve .
```

然后浏览器打开 `http://localhost:8080/`。

- `index.html` — 游戏本体（单文件可直接运行，无需构建）
- `shared.js` — 复用的 NPR / Toon 工具：种子化 PRNG、Perlin 噪声、3 阶 Toon gradientMap、反向外壳描边（`addOutline` / `addInstancedOutline`）、弹簧（`Spring`）。`index.html` 通过 `import` 复用，未重写。

## 操作

| 操作 | 方式 |
|---|---|
| 放火把 | 左键点击 / 拖拽到地形（预算有限，贴地预览圈） |
| 删火把 | 右键点击 / 移动端长按 |
| 快进 | 按住「快进」按钮，或按住 `Shift`（时间 1.6×，小人更快也更怕） |
| 重置本关 | `空格` |
| 换花园装饰种子 | `R` |
| 取消 / 关帮助 | `Esc` |
| 自转 / 描边 / 音效 / 日夜滑块 | 左上 Neo-Brutalism 面板 |
| 关卡切换 | 左上「上一夜 / 下一夜」或下拉框；含「无尽夜路」程序化模式 |

小人只走被照亮的路：先点亮他脚下的格子，他才会迈步；沿途每格都要有光，否则他会在黑暗里害怕、缩成一团。天黑前走到床上 = 到家了；天黑或恐惧值满 = 他还没到家，可无限重试。

## 关卡

12 关手工关卡（丘陵 → 河谷 → 林间 → 缓坡 → 石脊 → 碎石 → … → 最后一夜·悬崖），地形、火把预算、天黑速度各异；外加一个随机生成的「无尽夜路」。

## 技术要点

- **暗色温柔黄昏**：非体素低多边形浮岛，`PlaneGeometry` 细分 + Perlin 噪声起伏，`toNonIndexed()` 后 `computeVertexNormals()` 得清脆面着色。
- **全局 Toon**：`MeshToonMaterial` + Canvas 动态生成的 3 阶灰度 gradientMap（NearestFilter）。
- **反向外壳描边**：沿法线膨胀 + `BackSide` 黑色，统一 `addOutline` / `addInstancedOutline`，可开关。
- **省光照**：火把本体只用 4 盏 PointLight 照近处；地形明暗由「每格到最近火把的距离」写入**顶点色**完成（放置/删除增量更新受影响区域），远处靠顶点色——看起来有光、算起来很省。火把用 `InstancedMesh`。
- **A\* 寻路**：8 向网格，代价函数加「黑暗惩罚」；火把变化时 0.2s 节流重算。
- **恐惧第二层**（不看任何数字）：体态（直立→抱膝）、颜色（暖白→灰蓝，弹簧过渡）、影子（夸张拉长）、心跳（WebAudio 低频脉冲，随恐惧加速）、光本身（暖橙近 / 冷蓝远）。恐惧由「到最近火把的距离」直接驱动，不用弹簧。
- **种子化**：所有随机走 PRNG，重新生成种子可复现。
- **正交等距相机** + `OrbitControls`（限制极角、禁穿地、自转切换）；`DirectionalLight` 硬阴影 `PCFShadowMap`；日夜滑块驱动太阳方位 / 色温 / 阴影长度 / 环境色。

## 关于音频

规范允许优先尝试 `https://o.xbottle.top/mcsounds/` 的 MC 音效，失败回退 WebAudio 合成。为保证**零 console error**（沙箱离线时网络请求会污染控制台），本作**有意不发起该网络请求**，统一使用 WebAudio 合成：放置（木哒+呼）、删除（噗）、胜利（三音上行）、失败（低频下沉）、心跳（第二表达层，可关）。如需启用 MC 音效，在 `sfxPlace` / `sfxDelete` 内解除对应网络调用即可。

## 已知限制

- 必须经由本地服务器运行（见上），`file://` 直开会被模块策略拦截。
- 小人跟随光照 A\* 路径；若全程黑暗仍会找到一条高代价的「黑暗路径」并边走边怕——请沿途铺光。
- 目前未接入真实太阳光盘，黄昏地平线质感由背景渐变 + 低角度硬光共同呈现。
- 移动端触控拖拽放置可用，但精细穿模无法完全避免；长按删除已支持。
