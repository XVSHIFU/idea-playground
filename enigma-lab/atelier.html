A FIELD GUIDE TO ENIGMA

理解机器如何思考

01 / 每次按键发生什么？

按键先推动棘爪，使转子前进，再闭合电路。信号依次通过插线板、入线轮 ETW、右/中/左转子、反射器 UKW；随后经过左/中/右转子的逆向接线，再经 ETW 与插线板点亮灯泡。ETW 在此型号中是恒等接线。

02 / 怎样解密？

双方必须使用相同的转子顺序、环位、反射器、插线和报文起点。这里的“回送解密”会自动恢复本次起点，再处理当前输出。反射器成对连接且无自连，因此同一设置下加密互逆，字母永远不会映射到自身。

03 / 窗口与环位，是两种不同的设置

窗口位置 p 是转子当前角度；环位 r 决定字母环与内部接线的相对位置。令 A=0，B=1，…，Z=25，W 为原始接线置换：

去程：y = ( W[(x + p − r) mod 26] − p + r ) mod 26 回程：y = ( W⁻¹[(x + p − r) mod 26] − p + r ) mod 26

此型号的缺口随字母环一起运动，所以改变环位不会改变窗口所显示的进位字母。I、II、III、IV、V 的进位前窗口分别为 Q、E、V、J、Z；这与缺口在实体零件上的几何位置不是同一个标记。

04 / 双步进：它不是普通的里程表

在步进前读取缺口：若中转子在缺口，左转子前进；若右或中转子在缺口，中转子前进；右转子始终前进。三个条件同时依据按键前状态判断。

06 / 模型与操作说明

拖动三维机身旋转，滚轮或双指缩放。也可选中三维视图后用方向键转动，用 + / − 缩放。点击三维按键或下方虚拟键盘输入；点击三维转子向前拨一格。拆解视图展示真实置换关系对应的 26 条内部连线，外壳、比例和棘爪结构为教学抽象。标注模式帮助识别部件。

本模拟器保留末次灯号方便阅读。数字、标点、空格、汉字不进入电路；原机仅有 26 个字母键。撤销、批量输入和慢放是辅助功能。消息最多保留 5,000 个字母，可用“回到报文起点”重新开始。
