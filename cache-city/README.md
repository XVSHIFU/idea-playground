# 缓存之城

基于上级目录 `cache_city.plan.md` 的本地互动短篇原型。

## 运行

需要 Node.js 18 或以上版本，无需 npm install。

```powershell
cd C:\Users\Xvsf\Documents\TEMP\cache-city
npm start
```

浏览器访问 http://127.0.0.1:4187 。也可双击 `启动.cmd`。不要直接双击 index.html，浏览器会限制本地 ES 模块。

## 游玩

- 从白房间出发，点击相邻地点行走。到过钟楼后回家，可以完成一次委托。
- 每移动一步，未访问地点累积遗忘；每三步发生一次漂移，最多两个阶段。阅读和留下锚言不消耗步数。
- 回访将该地点遗忘计数清零，保留当前版本。
- 最多在两个地点保留锚言；满额时明确选择替换。不同句子在地点最后阶段改变叙事。
- 钟楼第二次漂移后解锁院子。尝试留下“3:17。”或“这里曾经有一口钟。”。
- 行程自动保存在当前浏览器的 localStorage；重新开始会清空此游戏存档。

## 开发

`engine.js` 是独立状态逻辑，`app.js` 负责界面，`style.css` 包含响应式样式。`npm test` 执行 Node 内置测试。无模型调用、账号或联网依赖。当前为有固定分支的短篇原型，不包含自由输入与无限生成。

浏览器检查：先 `npm install` 安装开发依赖，启动服务后运行 `node browser-check.mjs`。检查脚本使用本机 Microsoft Edge；涵盖移动、锚言、刷新恢复、委托、替换、重置与手机溢出检查。截图保存在 `.impeccable/review/`。
