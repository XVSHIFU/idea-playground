# Story font

`story-serif.ttf` is a Noto Serif SC Regular subset served by Google Fonts, downloaded for the characters present in index.html, engine.js and app.js. License: SIL Open Font License, included as OFL.txt. Upstream: https://github.com/notofonts/noto-cjk . Font delivered locally; gameplay makes no font-network requests.

When adding story text, regenerate the subset or provide a complete font. Missing glyphs fall back to the system Chinese serif.
